Extra tools for Jarvis. Most people only need setup.bat and the Desktop shortcut.

create_desktop_shortcut.bat  Puts a Jarvis shortcut on your Desktop again (e.g. after moving the folder).
install_startup.bat          Makes Jarvis start automatically when you log in to Windows.
remove_startup.bat           Stops Jarvis starting automatically at login.
start_jarvis.bat             Starts Jarvis voice-only in a console window (shows logs; press p to pause).
update_jarvis.bat            Updates Jarvis with git pull (only if you downloaded it with Git, not as a ZIP).
